# MinuSessionStore v0.1.0

MinuSessionStore v0.1.0 is an experimental local-first archive for Pi coding-agent sessions on macOS.

It preserves stable session JSONL prefixes as exact immutable bytes in a private, versioned S3 bucket and stores searchable operational metadata in a user-owned SQLite catalog. A launchd-managed daemon handles discovery, debounce, upload, verification, retention, and serialized catalog writes.

## Highlights

- Exact-byte Pi v3 JSONL capture with SHA-256 checksums
- Immutable, encrypted, independently verified S3 versions
- User-owned SQLite catalog and versioned read view
- Private Unix-domain daemon control socket
- macOS LaunchAgent installation and restart
- Persistent sync jobs, retries, debounce, and maximum-wait checkpoints
- Session metadata search, source filters, and exact S3 object location
- Sampled or full exact-version archive verification
- Safe reconciliation of legacy missing S3 `VersionId` values
- Retention planning and exact-version deletion with a grace period
- Catalog backups, Doctor diagnostics, bounded logs, and least-privilege IAM guidance

## Install

Requires macOS and Node.js 22.19 or newer.

```bash
npm install -g https://github.com/minuscule-labs/minu-session-store/releases/download/v0.1.0/minuscule-labs-session-store-0.1.0.tgz
minu-sessions --help
```

Then follow [`docs/usage.md`](https://github.com/minuscule-labs/minu-session-store/blob/v0.1.0/docs/usage.md) to provision or select a private S3 bucket, configure Pi discovery, run Doctor, and explicitly install the LaunchAgent.

## Security

Pi sessions may contain source code, prompts, tool output, filesystem paths, and accidentally printed credentials. Review the security and IAM documentation before syncing real sessions. MinuSessionStore does not include AWS credentials in its configuration.

## Supported scope

This release supports:

- macOS
- Node.js 22.19 or newer
- Pi v3 JSONL sessions
- Local SQLite
- Direct private S3 storage
- Per-user launchd supervision

## Known limitations

- Linux and Windows service management are not supported.
- npm registry and Homebrew distribution are deferred; this release installs from its GitHub artifact.
- Transcript content search, summaries, embeddings, restore, and local eviction are not included.
- Hosted libSQL schema compatibility is preserved, but the hosted workflow is not the MVP default.
- The release remains under an evidence-gathering stabilization period.

The raw S3 archive is authoritative. Derived metadata can be rebuilt or migrated, but raw session objects must never be parsed and reserialized in place.
