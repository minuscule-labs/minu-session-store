# MinuSessionStore v0.1.1

This stabilization release adds an explicit, checksum-verified update workflow for the GitHub distribution channel.

## Highlights

- `minu-sessions update --check` checks the latest GitHub release without changing the installation.
- `minu-sessions update` downloads the matching package and `SHA256SUMS`, verifies SHA-256, and updates writable global npm installations with lifecycle scripts disabled.
- A running macOS LaunchAgent daemon is restarted after successful installation so it loads the new code.
- Source checkouts, linked packages, unknown package managers, and non-writable installations are not modified.
- Early-closing stdout pipes now terminate cleanly instead of reporting `EPIPE`.
- Uninstall and local-data removal behavior is explicitly documented.

The updater does not run automatically or from the daemon. Configuration, catalogs, Pi sessions, AWS credentials, and cloud archives are preserved.

## Upgrade from v0.1.0

Version 0.1.0 predates the update command, so install this release once using:

```bash
npm install -g https://github.com/minuscule-labs/minu-session-store/releases/download/v0.1.1/minuscule-labs-session-store-0.1.1.tgz
```

Future compatible releases can then be installed with:

```bash
minu-sessions update
```
