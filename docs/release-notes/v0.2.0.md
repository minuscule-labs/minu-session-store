# MinuSessionStore v0.2.0

This release adds safe, exact-version recovery of archived sessions and macOS Pi session rehydration.

## Highlights

- `minu-sessions sessions restore` retrieves an exact cataloged S3 object version into a user-selected path.
- Restores stream data to private temporary storage, independently verify size and SHA-256, and publish atomically.
- Existing files are protected unless restore is explicitly run with `--overwrite`.
- `minu-sessions sessions rehydrate plan` previews where an archived Pi v3 session would be installed without downloading content or changing Pi files.
- `minu-sessions sessions rehydrate apply` verifies and atomically installs exact native bytes into an existing Pi session root after explicit `--yes` confirmation.
- Rehydration detects identical sessions and conflicting IDs or paths, refuses overwrites, and preserves native working-directory and parent-session metadata.
- Builds now clean `dist/` first so local release packages cannot contain stale output.

The first rehydration adapter supports Pi v3 sessions on macOS. Other harnesses can continue using exact restore to a neutral path until a harness-specific adapter is available.

## Upgrade from v0.1.1

Check and install the release with:

```bash
minu-sessions update --check
minu-sessions update
```

Configuration, catalogs, source sessions, AWS credentials, and archived S3 objects are preserved.
